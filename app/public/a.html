Flow

  1. Browser requests /a/ with no session.
  2. APISIX redirects to Zitadel's login page (authorization code + PKCE).
  3. User signs in; Zitadel redirects to /a/callback with a code.
  4. APISIX exchanges the code for tokens server-side and sets the session cookie.
  5. On each request APISIX adds X-Access-Token, X-ID-Token, X-Userinfo; OPA authorizes; the app reads the headers.
