Flow

  1. Page loads; JavaScript sees no token and shows “Log in”.
  2. The browser redirects to Zitadel with a PKCE challenge (no client secret; public client).
  3. User signs in; Zitadel redirects back to /b/?code=….
  4. JavaScript exchanges the code for tokens directly with Zitadel (CORS) and stores them.
  5. Each API call sends Authorization: Bearer to /api/*; APISIX verifies the JWT, OPA authorizes.
